# MOTOPEDIA ULTRA
نسخه ارتقایافته MOTOPEDIA — ساخته شده توسط ایلیا بنده‌ای.

### امکانات جدید
- Moto Lab با اسلایدر قدرت، حجم و وزن و پیشنهاد مدل نزدیک
- Moto Oracle / گردونه شانس
- Achievement / مدال‌های قابل باز شدن
- گاراژ و مقایسه با ذخیره در مرورگر
- دانستنی، واژه‌نامه، کوییز، برندها، فیلتر و جستجو
- Dark/Light
- Responsive

برای باز کردن: `index.html`
